# Raw-Filter

Fruit juice website with smooth animations. Different type of website which can be useful for various fruit juice brands.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion & Lenis smooth scroll
- **Icons**: Lucide React

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure
- `src/app/` - Next.js App Router pages and global layout
- `src/components/` - Interactive UI components and animations
- `public/` - Static assets and juice product imagery
